# Afaan Oromoo Islamic Fatwa Platform

A web platform for publishing Islamic fatwas in Afaan Oromoo
and Arabic.

## Main Features

- Browse and search published fatwas
- Submit questions to the scholar
- Watch embedded YouTube videos
- Manage fatwas through a protected admin dashboard
- Support Afaan Oromoo and Arabic

## Technologies

- Next.js
- Node.js and Express
- MongoDB and Mongoose
- Git and GitHub
